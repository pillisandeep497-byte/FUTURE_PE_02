## 4. TikTok-style pacing notes (for cross-posting)

- **Pattern interrupt at 1s and again at 9s** — a hard cut, a hand entering frame, or a text card that fills the screen.
- **Text overlay from 0s** — most viewers watch muted initially; the hook must be readable before the audio lands.
- **End differently:** replace the CTA card with a question that invites comments ("Has this happened to you?"). TikTok's algorithm weights comments heavily; Reels weights saves and shares.
- **Loop-friendly ending:** end on the "before" frame so the video loops back into the hook without a visible seam.
- **Do not** use Reels-style captioning with big animated text; TikTok audiences read smaller, natively-placed text as more authentic.

## 5. Caption & subtitle spec (for the editor)

| Setting | Value |
|---|---|
| Font | Clean sans (Inter / Poppins / system) — no script fonts |
| Position | Centre-lower, **above the bottom 20%** (platform UI covers that area) |
| Lines | Max 2, 3–5 words per line |
| Emphasis colour | Warm gold/amber on key words: `₹12,000` · `3–5 months` · `Free` · `No pressure` |
| Hook text | Larger size, first 2 seconds only, centre of frame |
| Safe zones | Nothing important in top 15% or bottom 20% of the frame |
| Accessibility | Captions mandatory in every variant — 85%+ of social video is watched muted |

## 7. Editor's checklist (CapCut export gate)

- [ ] Hook visible on screen within 1.5s
- [ ] Captions burned in, 3–5 words per line, no UI overlap
- [ ] First frame is not a logo or title card
- [ ] Audio normalised; trending track ducked under speech
- [ ] No shot longer than 3 seconds
- [ ] CTA on screen for the final 3 seconds AND spoken once
- [ ] Exported 1080×1920, H.264, under 60 seconds
- [ ] Watched once on a phone with sound off — does it still make sense?
- [ ] `Results vary` on screen if the cut shows before/after
- [ ] `#ad` in the caption if a paid creator appears
